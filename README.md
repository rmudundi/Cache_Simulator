# Cache Simulator

- Build a configurable C++ cache simulator(direc-mapped, Set-Associative, Fully-Associative) with LRU eviction, cycle cost modeling, and hit/miss statistics

Part 1:

- Object Oriented Programming with C++
- Cache implemented as a vector
- LRU logic done with a counter
- Cycle count done with fixed miss and hit values
    - Hit = 1 cycle
    - Miss = 5 cycles
- Debugged heap corruption using Valgrind
